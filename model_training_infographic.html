2 학습 모델 및 알고리즘
Ridge Regression 선형 / 해석용이

선형 가중치 규제를 적용하여 텍스트 계수가 과적합(Overfitting)되지 않도록 억제합니다.

Random Forest 앙상블 / 강건함

수많은 의사결정나무 예측을 결합하여 데이터 노이즈에 강인한 성능을 보입니다.

XGBoost GPU가속 / 고성능

Gradient Boosting 기반으로 연산 속도가 매우 빠르고 잔차 예측이 탁월합니다.

LightGBM 메모리 절약 / 효율

리프 중심 트리 분할로 학습이 가볍고 다차원 TF-IDF 피처 처리에 유리합니다.

3 학습 전략 및 하이퍼파라미터 튜닝
🧬

Optuna 자동 하이퍼파라미터 튜닝

베이지안 최적화 알고리즘 기반으로 최상의 XGBoost 및 LightGBM 하이퍼파라미터 조합을 탐색합니다.

⚖️

전용 검증 데이터셋(Validation Set) 적용

K-Fold의 중복 학습 오버헤드를 탈피하고, 명시된 20%의 전용 검증셋을 평가 기준으로 적용하여 튜닝 연산 속도를 약 3배 향상시켰습니다.

4 학습 목표 및 평가 지표
최적화 손실 함수 (MAE)
MAE = 1/n Σ |y_i - ŷ_i|

평균 절대 오차를 최소화하여 이상치 왜곡에 유연하도록 모델을 학습합니다.

MAE 평균 절대 오차 (예측 편차)
RMSE 평균 제곱근 오차 (큰 오차 패널티)
R² Score 결정 계수 (설명력 지표, 최대 1.0)
💡 데이터 분할 활용 가이드: 학습 데이터로 모델을 학습시키고, 검증 데이터(Validation Set)로 최적의 파라미터를 탐색 및 조기 종료하며, 최종 성능 평가는 절대 겹치지 않는 테스트 데이터로 진행합니다.
